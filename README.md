# UO Wildlands – Custom Scripts


**Custom scripts and modifications for ServUO Ultima Online servers.**

This repository contains **only the custom files** – no ServUO core.  
These files are designed to be added to an existing ServUO installation.

---

## What's Inside

- ✅ Custom Pets – Named Pets, Legendary Pets, Companion Mounts
- ✅ Custom Items – Transmog Potions, Storage Chests, Champion Monolith
- ✅ Custom Systems – Townhouses, Mercenaries, Corpse Retrieval
- ✅ Quality of Life – Free Skills, Global Chat, Enhanced Training Dummies

---

## Installation

1. Install **ServUO** (version 57)
2. **Back up your existing `/Scripts/` folder** before proceeding
3. Drop the contents of this repository into your `/Scripts/` folder, overwriting existing files when prompted
4. Compile and run your server
